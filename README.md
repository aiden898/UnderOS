# UnderOS

a very basic operating system that i made
will get updates time to time

use the "help" command after loading the OS

how to install
1. download the latest upload of UnderOS
2. use RUFUS to install on a drive
2-1. use QEMU if you dont want to use on real hardware
3. boot the image with bios or QEMU
4. after boot use "help"
